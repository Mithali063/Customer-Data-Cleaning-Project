# Customer Data Cleaning Project

## 📌 Objective
To clean and prepare raw marketing campaign data using Python (Pandas) and excel

## 🔧 Steps Performed
- Handled missing values using mean
- Converted date column to datetime format
- Removed duplicate records
- Standardized column names
- Verified data quality

## 📊 Tools Used
- Python
- Pandas
- Jupyter Notebook
- Excel

## 📁 Files
- Raw dataset
- Cleaned dataset
- Jupyter Notebook

## 🚀 Outcome
Clean and structured dataset ready for analysis
